# FCF-Ambassadors

Working files for Falls Church Forward's community ambassador and welcome pages.

- [`proposal/PLAN.md`](proposal/PLAN.md): the page consolidation plan and where each item stands.
- [`proposal/drafts/`](proposal/drafts/): page drafts, written as paste-in Custom HTML blocks for the WordPress site.
- [`proposal/previews/`](proposal/previews/): previews of the "New here?" menu.

## The ambassador map

The "Find Your Ambassador" map used to live here as `index.html`. That copy was removed on 11 November 2026 because it duplicated the one on the WordPress site, which is the only version to maintain from now on. The old file is still in this repository's history if it is ever needed.
